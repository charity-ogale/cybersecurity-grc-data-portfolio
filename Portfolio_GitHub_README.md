### 3\. Apache Tomcat Version and Vulnerability Scan Troubleshooting

**Objective:** Investigate why a Nessus scan did not report
vulnerabilities for an Apache Tomcat 8.5.50 lab installation that
appeared outdated.

**Activities** - Practiced checking application versions and verifying
service/port availability. - Considered whether the target, scan policy,
plugin status, service detection, and scan configuration could affect
results. - Reviewed the importance of validating scanner results against
reliable vendor information.

**Key lesson:** A clean vulnerability scan is not, by itself, proof that
a system is secure. Results should be validated and the limitations of
the scan documented.

**Evidence to add** - Installed Tomcat version screenshot - Service/port
verification screenshot - Nessus scan configuration and results
screenshot

### 4\. CIS Benchmark / Security Configuration Assessment

**Skills demonstrated:** Security controls review, compliance
