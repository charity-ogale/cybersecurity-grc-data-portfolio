# Metasploit Practical Penetration Testing

## Project Overview
This project documents practical penetration testing exercises performed using the Metasploit Framework in a controlled lab environment.

## Objectives
- Understand the Metasploit Framework.
- Explore basic penetration testing workflows.
- Identify and examine vulnerabilities in a lab environment.
- Understand how exploits and payloads are used in authorised security testing.
- Document findings and security observations.

## Tools and Environment
- Kali Linux
- Metasploit Framework
- Controlled lab environment

Details of the practical exercises will be documented based on the completed lab activities.
