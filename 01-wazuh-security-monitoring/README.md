# Wazuh Security Monitoring and Threat Detection

## Project Overview

This project involved deploying and configuring Wazuh as a security monitoring and endpoint detection platform in a controlled lab environment.

## Tools and Technologies

* Wazuh 4.14.2
* Kali Linux
* Windows 11 Pro
* Wazuh Dashboard
* Security Configuration Assessment (SCA)
* File Integrity Monitoring (FIM)

## Activities Performed

* Deployed and configured the Wazuh Manager and Dashboard.
* Connected Windows and Linux agents to the Wazuh Manager.
* Monitored endpoint security events and alerts.
* Reviewed Security Configuration Assessment results.
* Explored vulnerability detection and threat hunting.
* Monitored file integrity and security events.

## Key Learning Outcomes

* Understanding endpoint security monitoring.
* Analysing security alerts and events.
* Assessing endpoint configurations against security benchmarks.
* Understanding vulnerability management and threat detection.
