### Linux File Permissions and Ownership

- Created a practice directory using `mkdir`.
- Created a test file using `touch`.
- Inspected file permissions using `ls -l`.
- Modified file permissions using `chmod 640`.
- Verified the updated permissions.

**Key Learning:** Understanding Linux permission levels for file owners, groups, and other users.
