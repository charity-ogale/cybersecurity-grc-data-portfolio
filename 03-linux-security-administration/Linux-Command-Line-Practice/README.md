Linux Command-Line Practice

Project Overview

This project documents my practical experience using Linux command-line tools in a Kali Linux environment. It demonstrates my ability to navigate the Linux terminal, manage files, monitor system information, configure permissions, and perform basic system administration tasks.

Practical Sections

1. File and Directory Management

Practised commands for creating, navigating, listing, copying, moving, and deleting files and directories.

2. Reading and Managing Text Files

Practised commands for viewing, searching, and managing text files.

3. System Information and Monitoring

Used Linux commands to inspect system information, monitor processes, and review system resources.

4. Networking Commands

Practised commands for examining network interfaces, connectivity, and network information.

5. User and Permission Management

Explored user-related commands and Linux file permissions.

6. Package Management

Practised package management operations using Linux package-management commands.

7. Archive and Compression

Worked with commands for creating, compressing, extracting, and managing archives, including tar, gzip, zip, and unzip.
